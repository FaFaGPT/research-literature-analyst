# Real screenshot capture checklist

No real application screenshots are currently stored here. Use this directory for screenshots captured during a documented run, following [the demo guide](../demo/README.md).

- **Obsidian vault:** show the actual files and working navigation; identify the run and whether the source material is real or synthetic.
- **Paper note:** make a method explanation and its source location legible. Do not display fabricated numerical results.
- **Research map:** show Motivation, theory, a direction and the Claim/evidence relationship; the graph view is optional.

Keep capture metadata in the demo run note: date, source run, shown file, and any cropping or redaction. Do not manufacture UI, fill empty areas with invented output, or reuse an illustration as proof of execution. If synthetic fixtures are shown, label the image synthetic and do not place it under a real-demo claim.

Use readable filenames such as `obsidian-vault.png`, `paper-note.png`, and `research-map.png` only when those images actually exist. The READMEs currently link to instructions instead of nonexistent media.
