# 精读与研究判断标准

## 阅读层次和表达

先用 150–300 字左右概括问题、思路、主要发现和与当前研究的关系，再深入解释。篇幅由信息量决定，不用长段落掩盖未理解的细节。

核心论文中的每个重要判断写成“结论 + 依据 + 适用条件”。原文定位可用 `[原文](来源链接)，§3.2，Eq. (4)`；没有页码时用章节和段落描述。数字来源精确到实验条件和表格位置。不要杜撰链接锚点或页码。

阅读状态含义：

| 状态 | 可以写什么 |
| --- | --- |
| metadata-only | 核实书目信息、可能相关性；不能写成论文发现 |
| abstract-only | 摘要明确陈述的问题和结论；方法与实验细节待核实 |
| partial-full-text | 只对实际读过的章节作判断，列出未覆盖部分 |
| full-text | 已读正文各相关部分；附录和代码仍需分别注明阅读情况 |

候选筛选允许短卡。核心方法论文只有标题、摘要或他人解读时，不能标成完成精读。引用综述对原论文的评价时，明确写“综述作者认为”，不能将其当作已核实的原论文结果。

## 动机与理论论文

围绕以下链条组织叙述：现象或理论矛盾 → 原有解释 → 解释失败的条件 → 本文的理论推进 → 对本题目的意义。

需要回答：

- 科学问题：作者解释的对象、分析单位与边界是什么？“重要”“广泛应用”不能单独构成研究动机。
- 构念：核心概念如何定义，和相近概念有什么区别；如何操作化或测量，是否存在代理变量偏差。
- 理论谱系：理论由谁提出、何时形成、依赖哪些前提、如何被后续工作继承或修正。按真实证据写，不为每个理论强行画线性发展史。
- 机制与命题：变量关系、因果方向、机制、调节或中介条件；箭头表示假设关系还是识别出的因果关系。
- 证据：数学证明、观察研究、受控实验、访谈或案例分别支持什么；相关性不足以单独支撑因果结论。
- 边界：适用人群、场景、尺度、分布和条件；反例或互相矛盾的结果。
- 研究关联：能支撑总题目的哪个 motivation，能导出哪个方向的可检验问题。

纯理论工作重点解释定义、定理、关键假设、证明思路与反例；无需填造数据集或训练过程。经验理论工作仍要交代样本、设计与实证证据。

## 方法论文：具体到可以重建主要思路

### 1. 问题形式化

说明任务、输入、输出、可观测信息、约束、评价目标和关键假设。使用符号表解释公式；维度或单位影响理解时写明。

### 2. 最接近的已有方法

选真正解决相同或相近问题的工作，说明其如何运作、在什么条件下出现什么不足，以及本文改变了哪一步。不给未读过的 baseline 编造机制。

### 3. 方法设计

对每个关键模块解释：输入 → 运算或机制 → 输出 → 为什么需要 → 如何与其他模块配合。用一个小例子或步骤流程贯穿全文，必要时给伪代码或简明 Mermaid 图。

不仅写模块名称，也解释作者为何选此设计、替代方案是什么、改变了哪种假设或归纳偏置。作者没有解释的动机标为“分析推断”。不能把多个常见部件的组合自动评价为机制创新。

### 4. 数学与算法

呈现原文关键公式，逐项解释含义及作用；讲清目标函数与约束、关键推导或证明步骤、优化或求解过程。区分原文公式、等价改写和教学用推导，标注推导依赖的额外假设。

训练方法交代监督信号、样本或负例构造、损失项与权重、更新哪些参数、预训练或初始化、训练与推断的区别。非训练方法解释求解器、搜索策略、终止条件或识别策略。

### 5. 资源和复现边界

交代原文报告的复杂度、数据和计算成本、参数规模、主要超参数、实现约束及代码可用性。没有读代码就不宣称核验了实现；有代码不等于已经复现。实验运行、下载大数据、安装依赖按本次请求范围决定，不是阅读任务的默认动作。

## 实验：数值、设计与论断对应

按下列问题解释核心实验，不只抄排行榜：

1. **实验检验什么？** 每项实验对应性能、机制、泛化、稳健性或效率中的哪项论断。
2. **数据是什么？** 来源、版本、样本量、纳入条件、采集或标注过程、训练/验证/测试划分、泄漏风险；区分人数、样本数、试次数等单位。
3. **比较是否公平？** baseline 的选择、实现和调参，训练数据、参数规模、计算预算、外部知识、工具与预训练条件是否相同。
4. **指标说明什么？** 指标定义、单位、越大或越小越好、对科学问题的意义和盲点。
5. **结果有多大？** 报告关键 baseline 和本文方法的原始数值，必要时计算差异，注明计算方式；区分百分点、绝对变化和相对变化。
6. **变化是否可靠？** 重复次数、随机种子、方差/标准差/置信区间、统计检验和效应量分别是否报告。缺少检验时不把提升写成统计显著。
7. **机制得到什么支持？** 消融移除了什么、是否保持其他条件相同、结果能否排除额外参数或数据等替代解释。消融结果不自动证明因果机制。
8. **何时失败？** 分布外测试、敏感性、负面结果、失败案例、资源代价，以及没有检验的主张。

推荐结果表：

| 数据/任务与划分 | 实验条件 | 方法/对照 | 指标与方向 | 数值及不确定性 | 原文定位 | 可支持的结论 |
| --- | --- | --- | --- | --- | --- | --- |

表格无法可靠提取时查看原表图像；仍不确定则标记待核对，不猜数字。跨论文的数据版本、划分或预算不一致时列明条件，不能直接合并排名。

## 批判分析与审稿视角

按证据评价，不套固定的“数据少、泛化不足、未来扩大样本”三句话。

- 贡献属于新问题、新理论、新方法、新数据、新实验发现中的哪一种或几种？是支持新解释，还是在既定任务上改善指标？两者价值分别是什么？
- 最有说服力的证据是什么，解决了哪个已有不足？
- **作者承认的局限**与**分析发现的局限**分开写，后者给出依据和成立条件。
- 以审稿人身份提出 2–4 个具体问题，并说明要补什么证据才能回答。问题要关联本文主张，例如某项比较混入了数据量差异。
- 不把缺少某项可选实验直接写成致命缺陷，也不把 venue 或引用量当作结论可信度的替代指标。

## 从空白到可执行研究

对有潜力的方向写明：

| 要素 | 内容 |
| --- | --- |
| 缺口与来源 | 理论、方法、数据或应用方面的不足，以及支撑和反对证据 |
| 缺口状态 | 作者提出／当前检索范围内尚未找到解答／相互矛盾／研究者推断 |
| 最接近的工作 | 已经做到哪里，本设想和它的实质差别 |
| 可证伪假设 | 什么可观测结果会支持它，什么结果会推翻它 |
| 拟议方案 | 从哪个机制出发改变哪个环节，以及理由 |
| 最小验证实验 | 需要的数据、对照、指标、消融和基本资源 |
| 失败或停止标准 | 什么结果说明方向暂不值得继续 |
| 可行性 | 数据可得性、计算/实验成本、关键依赖与风险 |

所有尚未执行的方案写为“研究设想”，不填预测数值装作实验结论。创新性只在已声明的检索范围内评价，不保证“无人研究”或能够发表。
