# Examples

These examples explain the intended workflow. **No real-paper analysis, scientific findings, or benchmark results are claimed.** Domain READMEs describe how to select real inputs; any included vault is labeled illustrative/synthetic.

| Domain | Research question type | Evidence emphasis |
| --- | --- | --- |
| [Psychology](psychology/README.md) | When might oversight affect perceived accountability? | Constructs, design, population, measurement and boundary conditions |
| [Machine learning](machine-learning/README.md) | When might a retrieval change improve performance under a fixed budget? | Dataset, split, baseline, compute, implementation and uncertainty |
| [Interdisciplinary](interdisciplinary/README.md) | When might an explanation improve calibrated human reliance? | Bridging model metrics, human behavior and competing mechanisms |

The intended navigation is research question → papers → claims → concepts → directions → evidence matrix → source locations. Links should work in both directions where useful. Claims must not turn an untested hypothesis into established knowledge.

A real example requires an accessible source pack, recorded prompt and tool conditions, original generated files, source verification, and an explicitly documented review. Synthetic fixtures must remain labeled when copied or shown in screenshots.
